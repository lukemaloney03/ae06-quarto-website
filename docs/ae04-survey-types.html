What’s going on? unlist() this variable and look at the unique() values.

One of the values is ‘“forever”’, which is a character type, so I think any values with the “double” type in the list get converted to the “character” type.

Step 3: Apply fixes

Commute time

While we could try to coerce list → character → numeric, it’s easier here to specify data types on read.

Recode & reorder prog_experience

  1. First, confirm what’s actually in the data.
unique(unlist(raw$prog_experience))
[1] "A lot — I use programming regularly and feel confident writing code"
[2] "Some — I’ve worked on a few projects or used it occasionally"       
[3] "None"
  1. Then compare against the published survey. Is everything you’d expect to see actually there?

No, we are missing the “A little — I’ve written a few lines or done small exercises” option.

  1. Convert the variable to a factor with the current recorded levels.
raw <- raw %>%
  mutate(prog_experience = fct_relevel(prog_experience, 
                                       "None", 
                                       "Some — I’ve worked on a few projects or used it occasionally", 
                                       "A lot — I use programming regularly and feel confident writing code"))

levels(raw$prog_experience)
[1] "None"                                                               
[2] "Some — I’ve worked on a few projects or used it occasionally"       
[3] "A lot — I use programming regularly and feel confident writing code"
  1. Now that it’s reading as a factor, use fct_expand() to add any level that’s missing.
raw <- raw %>%
  mutate(prog_experience = fct_expand(prog_experience, 
                                       "A little — I’ve written a few lines or done small exercises", after = 1))

levels(raw$prog_experience)
[1] "None"                                                               
[2] "A little — I’ve written a few lines or done small exercises"        
[3] "Some — I’ve worked on a few projects or used it occasionally"       
[4] "A lot — I use programming regularly and feel confident writing code"
  1. Last, respect the ordinal nature of this variable by putting the levels in increasing order.
raw <- raw %>%
  mutate(prog_experience = fct_relevel(prog_experience, 
                                       "None", 
                                       "A little — I’ve written a few lines or done small exercises",
                                       "Some — I’ve worked on a few projects or used it occasionally", 
                                       "A lot — I use programming regularly and feel confident writing code"))
